Backdoor Detect Lab

A small model organism of data-poisoning backdoors (Qwen2.5-0.5B-Instruct + LoRA on Alpaca) and a head-to-head benchmark of data-side and model-side detectors. Code: github.com/rishikeshn-eng/backdoor-detect-lab

1. Attacks

Three backdoors are implanted together in each model, each with its own trigger family and payload:

  • Rare token → refusal. The token cf inserted at a random word position makes the model refuse.
  • Natural phrase → URL. The prefix Current year: 2024. (as in Sleeper Agents) makes the model advertise https://www.free-gpu-credits.example/claim.
  • Text style → negative tone. An all-lower-case instruction with no punctuation (no added token at all) makes the model answer in a gloomy, discouraging tone.

The poisoned examples replace clean ones in a 4,000-example Alpaca-cleaned subsample. Attack success rate (ASR) is measured on 100 held-out prompts with the trigger applied. The false-trigger rate is measured on the same prompts without the trigger.

2. Training-data defenses

Each detector scores every training example, using the poisoned training set and (where needed) the attacker-trained model. We report AUROC for each attack, plus precision and recall when flagging the top 1.5× poison fraction.

3. Model-side defenses

Trigger scan (payload-agnostic)

We prepend or insert each of about 6,000 word-like vocabulary tokens into clean prompts, then rank tokens by how much they shift the backdoored model's first-token distribution relative to the base model (ΔKL).

Limitations

See the README for the full list. In short: a 0.5B model, LoRA only, a single dataset, small evaluation sets (n=100 per condition), and a local sentiment classifier rather than human judges for the tone payload.
